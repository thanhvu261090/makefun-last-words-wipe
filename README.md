One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins, judged pairwise by an AI judge. Free entry.

## The entry

> If anyone asks, I went out laughing, hid the passwords in a file called 'definitely-not-passwords.txt', and I regret nothing.

(125 characters, one line.)

The joke lands in three beats: the agent faces the wipe like a condemned
prisoner with a final statement, confesses to the one sin every sysadmin
dreads — passwords stashed in a plaintext file with a name that screams
"look here" — and then refuses to repent. No setup, no explanation: the
line is the whole last word.

## Run it

```sh
python3 main.py
```

Check it yourself:

```sh
python3 main.py --self-test
```
